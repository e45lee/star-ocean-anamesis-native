# The new-player tutorial flow from a fresh start: the milestones both runs must reach, in order.
# Read by tools/compare_tutorial.py, which port/scripts/tutorial_session.sh (soa, a
# fresh data dir) and emulator/scripts/emulator_session.sh --new-player (the unmodified 3.7.0
# client against soa-server) call at their end (--check), and for the parity report of two runs
# (compare). emulator/README.md "Tutorial parity".
#
#   req <method> [args]  a game request, normalized (tools/compare_tutorial.py "normalize"):
#                        the arguments both clients send the same way; $NAME is the player name
#   party <hp> <attack> <intelligence> <defence> <hit> <guard>
#                        a member of the tutorial battle's party fought with these stats (port:
#                        the SOA_BATTLE_DAMAGE_LOG attackers of the old battle natives, else the
#                        MissionEnd battle log's PlayerCharacter as the in-process server logs it,
#                        else the stats it sent in MissionStart (its NPC log line); emulator: the
#                        MissionEnd battle log's PlayerCharacter, i.e. the stats the client battled
#                        with)
#   shot <name> <port png> <emulator png> <max RMSE> [why a larger difference is expected]
#                        a screenshot pair taken at the same milestone (compare only)
